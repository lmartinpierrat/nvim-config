# minimal neovim config

This configuration is a minimal, lua based, configuration for neovim.
It can be used by whomever is interested, the configuration is specialized
for development of python, rust and c++ projects.

External from neovim:
- lua5.4
- liblua5.4-dev
- luarocks
- lazygit
- nerdfont

List of interesting plugins: 

https://github.com/xzbdmw/colorful-menu.nvim

The package manager used is lazy.nvim (https://github.com/folke/lazy.nvim),
with the following configured plugins:

- nvim-tree
- nvim-colorizer
- which-key
